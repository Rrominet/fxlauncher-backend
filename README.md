# fxlauncher(backend)

This is a program that can pipe informations about the system apps.  
It's not useful as is.  

It's used by other softwares like [fxcommander](https://github.com/Rrominet/fxcommander)

## Dependencies

Depends on [cpp-utils](https://github.com/Rrominet/cpp-utils)

*You don't need to install it, it's included in the installation script below :*

## Installation

You shouldn't build or install this repo alone (unless you want to modify it).

It will be installed automatically by the programs that depends on it.  
Like [fxcommander](https://github.com/Rrominet/fxcommander).
